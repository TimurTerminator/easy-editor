Easy Editor
A simple photo editor built with Python and PyQt. It features a clean interface for quick image adjustment and seamless file loading.
💡 Features:
▫ Left/Right - Rotate the image 90° counterclockwise or clockwise.
▫ Mirror - Flip the photo horizontally.
▫ Sharpen - Increase image details and sharpness.
▫ B/W - Convert the photo to black and white
▫ Blur - Apply a blur effect to the image.
▫ Save - Export the edited image to your PC
▫ Reset Filters - Revert all changed back to the original photo.
🙌 Enjoy using Easy Editor! Hope it helps you with your quick photo editing tasks!
